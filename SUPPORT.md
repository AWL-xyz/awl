# support

start with the [README](README.md), [syntax reference](docs/AESOP.md), [built-in API](docs/API.md) and [toolkit guide](docs/ASDK.md)

for build and test questions, see [current test gates](tests/README.md), include your host OS, compiler version and the exact command output

for bug reports, use the issue template and include a minimal `.aw` source plus the `acc` command, generated C and report hash when relevant

for security issues, follow [SECURITY.md](SECURITY.md), do not open a public issue with sensitive details

this repository does not currently offer a public registry, server `add`/`install` command, accepted native Windows-host SDK or complete source-current SDK release, those are development work rather than support channels
