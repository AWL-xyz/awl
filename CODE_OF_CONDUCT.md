# code of conduct

we want a practical, respectful place to work on an experimental language and compiler

## expected behavior

- be respectful and assume good intent
- review technical claims with reproducible commands and exact reports
- give actionable feedback about code, docs and tests
- respect private planning material and do not republish it

## unacceptable behavior

- harassment, personal attacks or discriminatory language
- publishing credentials, private notes or another contributor's unpublished work
- deliberately misleading capability, benchmark or platform claims
- repeated disruptive behavior after a maintainer asks for a pause

maintainers may edit or remove issues, pull requests and comments that violate these expectations, serious or repeated violations may result in a temporary or permanent ban

report conduct concerns privately to the repository maintainers through GitHub, please include links and enough context to review the situation
