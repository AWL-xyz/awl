Real source. An explicit browser subset.

This HTML includes the example source files, a parser, a source-to-JavaScript execution backend running in an isolated Web Worker, and a canvas implementation of the framebuffer window API. There is no server, external library, prerecorded animation, or donut-specific renderer in the browser runtime: the donut pixels are computed by the Awl source.

Supported: next-syntax scalar declarations, functions and nested helpers, return, if/else, while, assignments, arithmetic, math constants/functions, print, project-file imports with aliases, scalar exports, and framebuffer creation/pixel drawing/presentation.

Not native-equivalent: this is not the production compiler/checker. It does not implement the full type/ownership verifier, 64-bit integer behavior, native OS access, typed vectors, arrays, aggregates, enums, or the legacy dialect. Integers are limited to JavaScript safe integers. Some numeric coercions and error behavior differ. Unsupported syntax fails explicitly; the library includes examples that require native Awl.

Window adapter: windows are canvases, not OS windows. Polling currently returns no events; keyboard/mouse input and resize events are not emulated. Use Stop to close the running program. Sleep is asynchronous. Closing a window preserves its last frame for inspection. Workers have an execution budget and can always be terminated.

Project files: switching files preserves edits; entry chooses what runs. Relative imports resolve against the bundled editable file map. Export downloads a JSON snapshot containing every file. Save .aw downloads the current source. No autosave or telemetry.
